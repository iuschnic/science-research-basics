# Точность приближения Шустера — Шварцшильда

**Тема.** Исследование точности приближения Шустера — Шварцшильда при моделировании переноса излучения в средах с переменной по спектру оптической плотностью при заданном поле температур.

**Постановка.** Бесконечный цилиндр радиуса $R$ из ксенона, p = 1,5 МПа. Температура задана: $T(r)=T_0+(T_w-T_0)(r/R)^n$. Внешней подсветки нет, рассеяния нет, выполняется ЛТР. Коэффициент поглощения $k_\nu(T)$ задан таблицей на 193 частотных полосах ($\nu^*=\nu\cdot10^{-15}$ = 0,02…3,0) и 12 температурах (2000…13 000 К).

Сравниваются два метода:

* **точный** — уравнение переноса решается вдоль 960 прямых лучей в каждой точке ([разбор](EXACT_METHOD.md));
* **Шустер — Шварцшильд** — двухпоточные уравнения для $F^\pm_\nu(r)$ ([разбор](SCHUSTER_SCHWARZSCHILD.md)).

Сравниваемая величина — дивергенция лучистого потока $q_\nu(r)=\mathrm{div}\,F_\nu$ (Вт/(м³·Гц)) и её интеграл по спектру $Q(r)$ (Вт/м³), который входит в уравнение энергии.

## Запуск

```powershell
python -m pip install -r requirements.txt   # numpy, matplotlib
python main.py                              # расчёт, графики и таблицы в output/
python -m unittest discover -s tests        # проверки (~20 с)
```

Параметры варианта и настройки таблицы задаются в начале [main.py](main.py). Пункты с пометкой `TODO` требуют подтверждения преподавателя:

* единицы $k$ в файле (`K_UNIT_SCALE`: 1 — м⁻¹, 100 — см⁻¹);
* значения $T_0$, $n$, $R$ варианта;
* способ продолжения $k$ ниже 2000 К (`K_EXTRAPOLATION`), потому что по заданию $T_w$ = 1800 К.

## Что получается на выходе

| Путь | Содержимое |
|---|---|
| `output/exact`, `output/schuster_schwarzschild` | Спектры $q_\nu$ по радиусам, график $\tau_\nu$ |
| `output/comparison/values`, `error_percent` | Сравнение спектров и процентная ошибка на каждом радиусе |
| `output/comparison/integrated_div_flux_vs_radius.png` | $Q(r)$ обоих методов и $Q_{\rm ШШ}/Q_{\rm точн}$ по $r/R$ |
| `output/comparison/ratio_vs_tau.png` | $q_{\rm ШШ}/q_{\rm точн}$ в зависимости от оптической толщины полосы |
| `output/txt/*.txt` | Все численные результаты в виде таблиц (TAB-разделитель) |

## Ожидаемые пределы (проверяются тестами)

* Оптически тонкие полосы: $q_\nu\to4\pi k_\nu B_\nu$, методы совпадают.
* Оптически толстые полосы, диффузионный предел: $q_{\rm ШШ}/q_{\rm точн}\to3/4$ вне оси и $3/8$ на оси.
